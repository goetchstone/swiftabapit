# Working on swiftabapit

**abapit as a native macOS app**: SwiftUI, macOS 27 only, App Sandbox on, for the **Apple Business API
2.6**, the **Apple School Manager API 1.7** and **Mosyle Business**. On screen the app is **abapit**;
this repo is **swiftabapit**, the Xcode project `SwiftAbapit.xcodeproj`, the bundle ID
`io.github.goetchstone.swiftabapit` (permanent: the Keychain items and the sandbox container bind to it).
Public repo, MIT. The design and phases are in
[docs/plans/2026-10-16-swift-port.md](docs/plans/2026-10-16-swift-port.md); **read its phase Status
lines first.**

The credentials this app holds are the reason it is careful: **an Apple API key with a write role can
move every device in the organization to another MDM, or release devices from the organization for
good (`RELEASE_DEVICES`, irreversible); Mosyle admin credentials can lock or wipe devices.** Bearer
tokens, signed assertions and Mosyle JWTs are passwords for as long as they live.

abapit (the Python app, `../abapit`) is **frozen except fixes** (plan D9). It is the parity reference:
never edit it from here; read it, and generate fixtures from it at the pinned commit.

## Invariants — do not regress these

Numbered; a retired number is never reused. Each names its enforcement home. A change that
"simplifies" one is a bug.

1. **One write path.** Planner → `HeldPreview` (the exact request bytes) → operator confirm → Guard
   inside the `Executor` → audited send of **the held bytes**, never a rebuild. `HTTPCore.send(_:ticket:)`
   takes a `WriteTicket` only the `Executor` mints (`package` access). *Home: the compiler, and
   `SourceScanTests`.*
2. **Reads are classified by type, not by HTTP method.** Apple reads are GETs; a Mosyle read is a POST
   whose `(path, operation)` is on the read allowlist; everything else is a write. Only allowlisted
   reads run automatically. The Logs Stream consumes what it returns, so it drains only from the drain
   task. *Home: `MosyleRead`/`AppleRead` initializers are `package`; `SourceScanTests`.*
3. **Secrets live only in the Keychain** (data-protection, this device only, user presence). One listed
   exception: an org's optional unattended **read-only** key (plan D5, §3.4.4) is stored without user
   presence, after every write probe returned 403, and only a type with no route to a write may use it.
   Bearer tokens, assertions and Mosyle JWTs live only in actor memory. A `Secret` never prints, logs,
   encodes or dumps. *Home: `Secret`'s `package` bytes; `VaultTests`; the credential-guard hook.*
4. **No listener. Sandbox on. Host allowlist. Zero third-party dependencies.** Outbound HTTPS only to
   the five allowlisted hosts; a redirect elsewhere is refused; a presigned `downloadUrl` is opened in the
   browser, never fetched. *Home: `scripts/check_app.sh` (exact entitlements, keys and values; one
   Mach-O; no listener symbol), `HTTPCoreTests`, `scripts/check_graph.py` (the manifest SwiftPM
   evaluates) and the compiler's explicit-import check.*
5. **The stubs fail like the APIs.** `AppleStub` and `MosyleStub` are strict: an unhandled request fails
   the test, and each failure mode is written from the API's documented or recorded behaviour, never
   from convention. A stub also has a switch for every failure the client handles (a dropped connection,
   a revoked account, a short token, an oversized body, a 429), and a test drives each: a branch no stub
   can reach is untested (failure-log 2026-10-16, "the stub could not fail"). *Home: `TestSupport`; the
   `pre-commit` skill.*
6. **Parity is a test.** abapit's behaviour is held by goldens in `Tests/Fixtures/parity/`, generated by
   `scripts/gen_fixtures.py` from abapit at its pinned commit. Where abapit is wrong, the fixture holds
   the corrected expectation and abapit's output beside it, and a test keeps that deviation list
   short. Never edit a fixture to make a test pass. *Home: `ParityTests`.*
7. **Bound everything polled, streamed or swept**: pages (a cap, shown), activity polling (30 min),
   Logs Stream drains (pages and time per run), sweeps (cancellable, rate-limited), held previews (8,
   15 min). *Home: tests per bound.*
8. **Stale or truncated data is never silent.** Cached or snapshot data shows its age; a list cut at
   the page cap says "showing N of ≥M"; a section a probe found forbidden says "your role can't read
   this". *Home: screen-model tests.*
9. **A model or Siri only drafts**, except the operator's **safe-actions list** (plan D10, operator
   2026-10-16): off by default and switched on per org in Settings, a fixed set of single-device actions
   (Mosyle play sound and request location; assigning one device to a service), each read back,
   audited with its origin, through the same `Executor`, with undo where the API allows. Everything
   else needs the operator's click on the preview. `RELEASE_DEVICES`, deletes and destructive Mosyle
   commands can't even be drafted; lost mode and bulk changes can be drafted, never run from the list.
   Models are on-device only (D7). *Home:
   `SourceScanTests` (`noIntentReachesAWrite`), `ExecutorTests` (one per allowlist rule).*
10. **Decoding is forward-compatible.** Unknown keys are ignored and unknown enum values survive as
    `.unknown(raw)` (`OpenEnum`), shown raw. *Home: contract tests against `Contracts/apple/`.*
11. **Sensitive fields never leave the app**: Activation Lock bypass codes (`activation_bypass*`),
    tokens, assertions, passwords. The Mosyle adapter is an allowlist; CSV export is an allowlist.
    *Home: `RedactionTests`; `SourceScanTests`.*

## The recurring failure mode: the stub lies

abapit's and SwiftGamGui's defining bug class is **"the mock passed, the live tenant broke."** When you
touch `AppleStub` or `MosyleStub`, make it **fail the way the real API fails**, checked against
`Contracts/apple/*.json` (Apple's own DocC, machine-generated), `Contracts/mosyle/operations.json` and
the recorded responses in `Tests/Fixtures/recorded/` — not memory, not Postman alone. A stub more
permissive than the API turns a live break into a green test. **Passing tests do not mean a write
works.** A write is unproven until `live-verify` has run it on a scratch object.

## Rules of engagement

- **Never mutate a real tenant** (Apple or Mosyle) without the operator's explicit, per-action yes in
  this session's chat. Read-only checks need the operator's go too (`live-verify`).
- **Never touch credentials**: no `security find-*` on real items, no reading `*.pem` files or
  `~/.config/abapit/**`, never print a token or a key. Spikes use throwaway Keychain items named
  `swiftabapit-spike*` only. **Only the operator answers a Touch ID or Allow prompt.**
- **Never launch the real app on the operator's screen.** UI is checked through the env-var snapshot
  harness in CI (`scripts/screenshots.sh`), and spikes run headless (`ABAPIT_SPIKE`, no window).
- **Tenant data never enters the repo**: serials, names, emails and IDs in fixtures are scrubbed to
  format-preserving fakes and `example.com`; the local private-terms tripwire blocks the operator's terms.
- **Commits reach `main` only through a pull request whose `ci-ok` is green. Publish as goetchstone**:
  this Mac's `gh` has a second active account that must never appear here. Every `git push` and `gh`
  write runs with `GH_TOKEN="$(gh auth token --user goetchstone)"`, after `gh api user --jq .login`
  prints `goetchstone`. Never switch the global account.
- **One phase = one branch (`phase-<n>-<slug>`), one PR, one adversarial review agent.** Parallel
  branches live in `git worktree`s. Never stack a PR on a branch `--delete-branch` will remove.
- **Stop and hand to the operator** for: Touch ID or an Allow dialog, a signing team in Xcode, any
  live-tenant read or write, any design change to the write path (`Executor`, `WriteTicket`, Guard),
  and any open operator decision. Write what's needed in the PR or the plan's Status line, and move
  to something unblocked.

## How we build: KISS, and learn every round

The simplest design that keeps the invariants wins; no speculative abstraction, no tooling before a
need. If a phase grows past its scope, stop and propose a split. Every slice ends by writing down what
it taught — a failure-log entry, a RULE-FEEDBACK note or a runbook line — so the next round starts
smarter. Security and code quality are part of done, not a later pass. Port behaviour **test-first**:
a failing Swift test against a golden, then the code, then mutate the code by hand and record the
mutants killed in the PR.

## Working here economically

Scale subagents to the stakes: adversarial review earns its cost on credentials, signing, the write
chokepoint and parsers of API data; ordinary feature work needs one agent or none. A cheap
deterministic check goes before an expensive one. Long procedures live in `.claude/skills/`, not here.
Summarize large tool output instead of re-reading it. Research answers "what could we do"; the plan
keeps only what was asked for or what prevents a loss.

## Commands

```bash
scripts/test.sh                                                     # graph check, explicit-import build, package suite
xcodebuild -project SwiftAbapit.xcodeproj -scheme abapit -derivedDataPath build/DerivedData.noindex build
scripts/check_app.sh build/DerivedData.noindex/Build/Products/Release/abapit.app   # the release gate
../abapit/.venv/bin/python -I -B scripts/gen_fixtures.py --abapit ../abapit       # regenerate parity goldens
python3 -I -B scripts/apple_contracts.py --out Contracts/apple --examples Tests/Fixtures/docc  # Apple contracts
# Headless spikes (debug builds; no window): ABAPIT_SPIKE=keychain | model
ABAPIT_SPIKE=keychain build/DerivedData.noindex/Build/Products/Debug/abapit.app/Contents/MacOS/abapit
```

Command-line builds go in `build/DerivedData.noindex`: Spotlight skips a `.noindex` folder, and every
indexed copy of the app is one more app Siri can pick by name (SwiftGamGui RULE-FEEDBACK 2026-10-10).
Debug switches are **environment variables**, never launch arguments: AppKit reads `-key value` as
defaults and opens a leftover bare path as a document.

## The layered system

As in SwiftGamGui ([docs/FRAMEWORK.md](docs/FRAMEWORK.md)): this file is the **constitution**, loaded
every session; **domain runbooks** in [docs/domains/](docs/domains/README.md) are read before working in
an area; **skills** in `.claude/skills/` are procedures for a moment; **local hooks** (gitignored) inject
the orient digest, guard credentials, block a `fix:` commit without a failure-log entry and nudge
`improve-rules`. Sessions don't edit the numbered invariants directly: log the incident in
[docs/failure-log/](docs/failure-log/README.md), note the strain in
[docs/RULE-FEEDBACK.md](docs/RULE-FEEDBACK.md), and let `improve-rules` propose one edit, with
distance. Invariant numbers are never reused.
